# Chess CLI

[![Python](https://img.shields.io/badge/Python-3.14+-3776AB?logo=python&logoColor=white)](https://www.python.org/)

A small command-line chess game written in Python.

## Features
- Chessboard displayed directly in the terminal.
- Move highlighting.
- Check detection.

## Requirements
- Python 3.14+

## Usage
```bash
git clone https://github.com/magalha3s/chess-cli.git
cd chess-cli
python main.py
```
